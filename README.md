# Employee Management System

A Python-based Employee Management System using Object-Oriented Programming and JSON file handling.

## Features

- Add Employee
- Search Employee
- Update Employee
- Delete Employee
- Display All Employees
- Store employee data in JSON
- Input validation
- Duplicate employee ID checking
- Delete confirmation

## Technologies Used

- Python
- Object-Oriented Programming
- JSON
- File Handling
